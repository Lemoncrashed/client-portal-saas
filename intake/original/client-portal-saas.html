01

项目背景

本项目计划建设一套面向企业客户使用的：

多租户、完全白标、自托管 Client Portal SaaS 平台。

平台主要服务于咨询、设计、软件开发、代理服务、专业服务等 B2B 企业，为每一家租户提供独立的客户门户。

系统重点不是建设完整 CRM、ERP 或营销自动化平台，而是围绕以下核心场景：

企业客户门户 企业品牌白标 独立访问域名 客户及员工账号 文件共享 客户服务工单 报价单及 PI SaaS 订阅自动开通

整体产品方向参考 ClientPortal 类产品，但根据本项目实际需求进行轻量化建设，控制系统复杂度和初期投入。

02

项目建设目标

本项目完成后，平台运营方可以通过一套系统同时服务多个企业租户。每个企业租户拥有：

自己的 Logo 自己的品牌颜色 自己的企业信息 自己的员工账号 自己的客户账号 自己的文件 自己的工单 自己的报价单 自己的 PI 自己的独立域名

03

系统角色

本项目设计四类核心角色。

Platform Admin

3.1 平台管理员

负责整个 SaaS 平台运营。

  • Tenant 管理 / 开通 / 停用
  • 查看订阅状态、域名状态
  • 查看 SaaS 使用情况
  • 查看 Webhook、系统日志
  • 系统配置
Tenant Admin

3.2 租户管理员

每家企业客户的最高管理员。

  • 企业资料、Logo、品牌颜色
  • 自定义域名设置
  • 员工管理、客户管理
  • 文件、工单、Quote、PI 管理
  • Billing 状态查看
Staff

3.3 内部员工

租户内部工作人员。

  • 查看客户、管理文件
  • 处理工单
  • 创建 Quote / PI
  • 服务下游客户

V1 采用标准员工角色，不做复杂自定义权限编辑器。

Client

3.4 下游客户

企业租户所服务的最终客户。登录后只能查看自己的：

  • 文件、工单
  • Quote、PI
  • 个人资料

不能查看其他客户或企业内部数据。

05

核心功能清单

5.1 SaaS 平台管理

平台管理后台主要包含：

Dashboard

  • Tenant 总数量
  • Active Tenant / Suspended Tenant
  • Active Subscription
  • Domain 状态
  • 系统运行状态

Tenant 管理

  • Tenant 列表 / 详情 / 创建
  • Tenant 状态修改
  • Tenant 停用 / 恢复
  • Tenant 基本使用情况查看

Subscription 管理

  • Subscription 状态
  • 套餐、到期时间
  • Lemon Squeezy Subscription ID
  • Tenant 状态

Domain 管理

  • Tenant
  • 自定义域名
  • DNS 状态 / SSL 状态
  • 域名启用状态

5.2 多租户系统

系统必须支持多个 Tenant 共存。每一个 Tenant 数据完全独立，包括：

用户数据 客户数据 文件 工单 Quote PI 企业配置 域名 品牌信息
Tenant A ≠ Tenant B。任何 Tenant 用户都不能通过修改 URL、接口参数或其他方式访问其他 Tenant 数据。

5.3 企业白标 Branding

Tenant Admin 可以自行设置品牌。

企业资料

  • Company Name
  • Company Address
  • Website
  • Support Email
  • Phone
  • PDF Footer

品牌资产

支持上传 Logo、Favicon；支持设置 Primary Color、Accent Color、Background Theme。

自动应用于 Login、Dashboard、Button、Navigation、Quote、PI、PDF。

5.4 完整 White Label

下游客户访问 Tenant Portal 时，不出现平台开发商品牌。
不出现开发商 Logo 不出现 Powered by 不出现开发商网站 不出现开发商公司名称

Tenant 的 Logo、Company Name、Colors、Domain 将作为客户看到的品牌。

5.5 自定义独立域名

Tenant 默认可以拥有平台子域名，例如 company-a.portal.example.com，同时支持绑定自己的域名 portal.company-a.com。

Tenant Admin 输入自定义域名后，系统生成 DNS 配置提示：

DNS 配置提示

Type: CNAME
Name: portal
Target: xxxxx.platform-domain.com

用户完成 DNS 配置以后，平台自动验证。

5.6 SSL 自动配置

Custom Domain 验证通过以后，系统自动处理 HTTPS / SSL。Tenant 不需要手动上传 SSL 证书。

Waiting DNS Verifying SSL Pending Active Failed

成功以后可直接访问 https://portal.company-a.com。

5.7 员工管理

Tenant Admin 可以创建、邀请、禁用 Staff，并查看 Staff 状态。Staff 使用自己的账号登录系统。

5.8 客户管理

Tenant Admin / Staff 可以新增、编辑、邀请、禁用 Client，并查看 Client 详情。

Name Company Email Phone Status Notes

5.9 文件管理

Tenant Admin / Staff

  • 创建文件夹
  • 上传 / 下载 / 删除 / 重命名
  • 将文件关联给 Client
  • 搜索文件

Client

  • 查看自己的文件
  • 下载自己的文件
  • 上传允许上传的文件

5.10 文件安全

文件不能直接公开访问。只有具备权限的用户才能下载：

1Authorization → 2Temporary Secure URL → 3Download

防止通过文件 URL 访问其他 Tenant 或 Client 文件。

5.11 简易工单

Client

  • 创建工单
  • 查看工单
  • 回复
  • 上传附件

Staff

  • 查看工单、回复
  • 分配负责人
  • 修改状态 / 优先级
  • 关闭工单

5.12 工单状态

Status

Open In Progress Waiting for Client Resolved Closed

Priority

Low Normal High Urgent

5.13 Quote 报价单

Tenant Admin / Staff 可以创建 Quote，包含：

Quote Number Customer Date Expiry Date Product / Service Description Quantity Unit Price Tax Discount Total Terms Notes

5.14 PI Proforma Invoice

支持创建 Proforma Invoice，信息包括：

PI Number Customer Date Expiry Date Items Quantity Price Subtotal Tax Discount Total Payment Terms Notes

5.15 PDF 导出

Quote / PI 支持 Download PDF。PDF 自动使用 Tenant Logo、Company Name、Address、Brand Color 和 Contact Information。因此不同 Tenant 导出的文件拥有不同企业品牌。

06

订阅系统

平台订阅通过 Lemon Squeezy 完成。

6.1 Subscription 开通流程

1Tenant Customer → 2Checkout → 3Payment → 4Webhook → 5Create Tenant → 6Create Admin → 7Activate
Tenant Customer ↓ Lemon Squeezy Checkout ↓ Payment Successful ↓ Webhook ↓ Create Tenant ↓ Create Admin ↓ Activate Subscription ↓ Tenant Available

6.2 支持订阅生命周期

Subscription Created Subscription Updated Payment Successful Payment Failed Subscription Cancelled Subscription Resumed Subscription Expired

6.3 自动停用

当 Tenant Subscription 真正过期：

ACTIVE → EXPIRED → SUSPENDED

Tenant 数据不会立即删除。Tenant Admin 可以恢复订阅以后继续使用。

6.4 取消订阅

取消订阅以后，不立即停止服务。例如：

Billing 生命周期示例

用户已经支付到 10 月 1 日。9 月 15 日取消后，9 月 15 日～10 月 1 日仍然正常使用；10 月 1 日以后 Tenant Suspended。

这样符合标准 SaaS Billing 生命周期。

11

主要技术难点

11.1

多租户强隔离

最大风险：Tenant A 通过修改请求参数访问 Tenant B 数据。解决方式为多层保护：Tenant Resolver + Backend Tenant Scope + Database Row Level Security + Cross Tenant Security Test。

11.2

Custom Domain

系统未来可能存在几十、几百甚至更多 Tenant，每个 Tenant 都可能使用自己的域名。传统 Nginx + Certbot 人工维护模式不适合 SaaS。解决：使用 AWS CloudFront 多租户域名能力统一处理 Tenant Domain、DNS、TLS、Routing。

11.3

SSL 自动化

Tenant 不应该自己购买、上传和更新证书。由平台统一负责 Domain Validation → TLS Certificate → Deployment → Renewal，实现真正 SaaS 化。

11.4

White Label 完整性

不能只做到换 Logo，而要覆盖 Login、Dashboard、Browser Title、Favicon、Email、Quote、PI、PDF、Error Page，防止在某些页面出现平台开发商品牌。

11.5

Lemon Squeezy Webhook

Webhook 可能存在重复、延迟、乱序、网络失败。因此系统需要 Webhook Signature Verification + Webhook Log + Idempotency + Retry + Async Processing，防止 Tenant 重复创建、Subscription 重复处理、状态异常。

11.6

文件权限

文件系统必须同时处理 Tenant Permission + Client Permission。例如 Tenant A Client A 只能访问 Tenant A + Client A Files，不能通过文件 ID 访问其他文件。
