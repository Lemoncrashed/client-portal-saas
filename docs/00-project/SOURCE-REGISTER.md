# Source Register

Status convention: **CONFIRMED** / **PROPOSED** / **OPEN** / **REJECTED**. A status with no applicable item in a document is not implied.

## Handling rule

| Status | Rule |
| --- | --- |
| CONFIRMED | Original material is stored under `intake/original/` without edits. |
| CONFIRMED | Derived statements cite a source ID and relevant section. |
| CONFIRMED | Every future `CONFIRMED` assertion cites at least one `SRC`, `DEC`, `BMD`, `FMD`, `PDM`, or `CR` reference. |
| CONFIRMED | A source recommendation is recorded as `PROPOSED` until explicitly decided. |
| REJECTED | Do not infer details absent from the sources. |
